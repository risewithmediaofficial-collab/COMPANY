💬 FAQ:

  Q: Can employee fake GPS?
  A: System records all data. Add photo verification for security.

  Q: What if GPS is inaccurate?
  A: Increase radius in configuration (e.g., 1.0 km).

  Q: Can partial WFH work (morning/afternoon)?
  A: Yes! Use startTime and endTime fields in WFH request.

  Q: How to handle remote employees?
  A: Create virtual location or auto-approve their WFH.

  Q: Can I see all GPS locations?
  A: Yes! All data stored in attendance records.
